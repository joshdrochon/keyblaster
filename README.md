# KeyBlaster

A kids' typing game (grades 2–5, desktop, keyboard only). Pilot the *Lantern* from Earth to Pluto, blast word-asteroids by typing them, leave a lit beacon at every stop. A per-player learning engine keeps success near 85%.

Built for the Nerdy AI Hackathon (submissions close Fri Sep 18 2026).
